# Car Jigsaw

เกมต่อภาพรถยนต์บน Browser สำหรับเครื่อง PC สร้างด้วย HTML, CSS และ JavaScript แบบไม่ต้องติดตั้ง dependencies เพิ่มเติม

## วิธีเล่น

1. เปิด `index.html` ด้วย Browser
2. ใช้ภาพตัวอย่างด้านข้างกระดานช่วยดูตำแหน่ง แล้วลากชิ้นส่วนจากถาดไปวางบนกระดาน จุดใดก็ได้
3. ชิ้นส่วนที่วางผิดตำแหน่งจะยังคงอยู่บนกระดาน และสามารถลากย้ายได้ตลอด
4. วางชิ้นส่วนใกล้ช่องที่ถูกต้องเพื่อให้ชิ้นส่วนเข้าตำแหน่ง ความคืบหน้านับเฉพาะชิ้นที่ถูกตำแหน่ง
5. เสียงเอฟเฟกต์ตอนหยิบและวางจะเล่นขณะลากชิ้นส่วน เพลงประกอบแนวอิเล็กทรอนิกส์ชิล ๆ จะเริ่มหลังการกดหรือแตะครั้งแรก และปิดได้ด้วยปุ่ม **เพลง**
6. กด **เริ่มเกมใหม่** เพื่อสุ่มชิ้นส่วนและเริ่มรอบใหม่

ชิ้นส่วนจะสลับตำแหน่งแบบสุ่มเมื่อเริ่มเกมใหม่ เกมใช้ภาพ `car.webp` และแบ่งเป็นจิ๊กซอว์ขอบโค้ง 20 ชิ้นในรูปแบบ 5 × 4.
